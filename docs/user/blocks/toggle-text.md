# Toggle Text Block

The Toggle Text block displays collapsible content behind a title. Players tap the title to reveal the content underneath. It is always collapsed by default.

This block is useful for optional or supplementary content that you don't want to show upfront, such as:

- **Hints** — give players the option to get a nudge without spoiling the challenge
- **References** — cite sources or provide background reading without cluttering the page
- **Lore** — optional world-building for players who want more context
- **Spoilers** — content players should only read after completing a challenge
- **Explanations** — reveal the answer or reasoning after a checkpoint is complete

Content is formatted using Markdown. Check out the [Markdown Guide](/docs/user/markdown-guide) for more information.

## Options

**Small text** — renders the content in a smaller, more subdued style. Useful for references or fine print that is supplementary rather than central to the experience.
